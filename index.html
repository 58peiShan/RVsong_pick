🎵 設定 YouTube 串流播放

需要免費的 YouTube Data API 金鑰來自動搜尋歌曲。
搜尋結果會快取，之後不需重新搜尋。

  1. 前往 Google Cloud Console
  2. 建立專案 → 啟用「YouTube Data API v3」
  3. 憑證 → 建立 API 金鑰
  4. 將金鑰複製貼至下方

金鑰僅儲存在您的瀏覽器本機，不會上傳到任何伺服器。
